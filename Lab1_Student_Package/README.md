# Lab 1 student package

Open Lab1_Ngram_Language_Models.ipynb. This package includes all four text files and their integrity manifest.

## Google Colab

1. Download and unzip this package on your computer to access the notebook.
2. Open https://colab.research.google.com/ and choose File > Upload notebook. Select the .ipynb file.
3. Connect to a standard CPU runtime and run the first code cell.
4. When asked, upload the original Lab1_Student_Package.zip. The cell loads its data files.
5. Complete TODOs and submit CP1–CP6 in Moodle during class as instructed.

## Local Jupyter

Unzip the package, keep data/ beside the notebook, and open the notebook in Jupyter. Python 3.9+ is sufficient for the code. Jupyter itself is needed only to open the notebook locally. No extra Python packages, API keys, internet downloads or GPU are required by the lab code.

The starter notebook intentionally stops at unfinished TODOs. Tests use tiny examples, not the graded corpus answers. All checkpoint data files are fixed; do not edit them.

## Corpus

Version lab1-v1 is an original, artificial teaching corpus generated for this course. It has 1,608 training sentences, 220 development sentences, 240 test sentences and eight diagnostic sentences. It is not a benchmark of natural language understanding. Repeated templates and novel held-out combinations are intentional. No external dataset download is needed. See data/manifest.json for file hashes and provenance.
